# Design

Web rules on top of the Library's design system (`docs/02-brand/03-design-system/`): cream background, Georgia for
headings, the peach→pink gradient for every main button.

## Every screen, as drawn
Honey's round gradient face top left with her line in a white bubble beside it; a Georgia heading; rounded white
fields; one pill button in the gradient at the foot. Phone first, one column, generous space.
The drawings are rough: every one ends in a button called *Next*, even where it should say what it does.

## The kit in the code
`flexboxes/web/assets/kit.css` has three tokens (`--cream`, `--ink`, `--go`) and one class (`.go`, the gradient pill).
Nothing applies the cream or the fonts yet, so the live page is white, in Times.
