# Design system

Written up at the import from the site's kit (`flexboxes/web/assets/kit.css`) and the eight drawings; nobody has
designed it yet. `design-system.html` draws it.

| Token | Value | Used for |
|---|---|---|
| cream | `#FFF8F0` | every background |
| ink | `#3A2A20` | words |
| sand | `#F1E3D3` | borders of fields and bubbles |
| muted | `#9A8A7C` | placeholder words |
| go | `#E9A16B` → `#E77FA0` | the one main button on a screen, Honey's face |

Type: Georgia 600 for headings, the system font for the rest. Buttons are pills; fields and bubbles are rounded.
In the kit today: `--cream`, `--ink`, `--go` and `.go`; sand and muted live only in the drawings.
